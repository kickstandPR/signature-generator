Install in Gmail

  1. Click Copy signature above. (You'll see "Copied!" when it works.)
  2. In Gmail, click the gear icon (top right) → See all settings.
  3. Stay on the General tab and scroll down to Signature.
  4. If you have an old Kickstand signature here, delete it first. Then click + Create new, name it "Kickstand," click Create.
  5. Click into the empty signature box and paste (Cmd+V on Mac, Ctrl+V on Windows).
  6. Under Signature defaults, pick "Kickstand" for both FOR NEW EMAILS USE and ON REPLY/FORWARD USE.
  7. Scroll to the bottom of the settings page and click Save Changes.
  8. Send yourself a test email to confirm the Kickstand logo and all the links appear.
Why this one works everywhere: No embedded photo. The Kickstand logo loads from the website at send time, which keeps the signature well under Gmail's size limit. Should work on the first try in Gmail, Apple Mail, Outlook, or mobile.
If the logo shows as a broken image for some recipients: some email clients block external images by default and recipients have to click "show images." The text, links, and layout always render fine either way.
